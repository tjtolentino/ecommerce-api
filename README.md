# MSTConnect PH E-Commerce API

Starter Express API for Capstone 2

## Setup

1. npm install
2. npm start
3. Open <http://localhost:3000>

## Endpoints

- GET /
- GET /api/products
- GET /api/products/:id
- POST /api/products

## Current Limitation

Data is stored in an in-memory array and resets when the server restarts
